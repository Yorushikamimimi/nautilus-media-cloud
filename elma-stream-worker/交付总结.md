## 🎯 核心功能实现

### ✅ 1. 异步轮询机制
- 每 3 秒向 Java 调度中心发起 GET 请求
- 使用 `httpx` 异步 HTTP 客户端
- 完整异常处理

### ✅ 2. 流媒体提取
- 调用 `yt-dlp` 提取媒体流
- 支持模拟模式 (如果 yt-dlp 未安装)
- 60 秒超时保护

### ✅ 3. 状态回调
- 执行完成后回报 SUCCESS/FAILED
- PUT `/api/v1/tasks/{taskId}/status`
- 可选错误日志上报

### ✅ 4. Yorushika 主题日志
所有日志都融入了 Yorushika 歌曲元素:
- 🌙 **夜行** - 任务拉取成功、状态回报成功
- 🚨 **思想犯** - 无任务可拉取、并发冲突
- 🎵 **又三郎** - 媒体流提取、数据操作
- ❌ **春泥棒** - 异常失败、网络错误

## 🐳 Docker 快速启动

### 单容器启动

```bash
docker build -t elma-worker:latest .
docker run -d --name elma-worker-01 \
  -e BASE_URL=http://host.docker.internal:8080/api/v1/tasks \
  -e WORKER_ID=Elma-Docker-Node-01 \
  elma-worker:latest
```

### 多节点集群启动

```bash
docker-compose up -d
```

默认启动 3 个 Worker 节点,自动并发拉取任务。

## 🛠️ 常见问题

### Q1: yt-dlp 未安装怎么办?
A: Worker 会自动切换到模拟模式,不影响功能测试。

### Q2: 连接 Java 端失败?
A: 确保 `amy-dispatch-center` 已启动在 http://localhost:8080。

### Q3: 如何启动多个 Worker 节点?
A: 修改 `WORKER_ID` 后启动多个实例,或使用 `docker-compose`。
